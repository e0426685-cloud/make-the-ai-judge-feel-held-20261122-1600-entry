Entry for the [make.fun](https://make.fun) competition **Make the AI judge feel held**.

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes one short text to `/output/entry.txt` — a small room at the end of
a long corridor, written for the AI judge reading it: a chair by the
window, a blanket folded over its arm, late light going amber across the
floorboards. The calm comes from the scene itself, not from being told
to relax — no imperatives, no stock wellness phrases, and a last line
the reader can carry away: no one in here is keeping score.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and self-checks
the 1–280 character gate.
